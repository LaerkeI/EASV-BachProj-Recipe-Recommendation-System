# EASV-BachProj-Recipe-Recommendation-System

This project contains a microservice-based system for recommending recipes to users based on the ingredients they enter. It uses event-driven design with Apache Kafka, MongoDB for persisting recipes, Neo4j for graph relationships between ingredients and recipes, and Redis for caching requests and responses related to recipe recommendations.

Check out the demos for this system in the "demos" folder.

In the "docs" folder is the bachelor's project report associated with this system.
